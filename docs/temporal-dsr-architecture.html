The Engine Swap

A single DSREngine protocol sits at queue_privacy_request(), the sole entry point for all DSR dispatching. Everything above it (approval, identity verification) is engine-agnostic.

class DSREngine(Protocol):
    def dispatch_privacy_request(self, privacy_request_id, from_webhook_id, from_step) -> str: ...
    def dispatch_request_task(self, request_task_id, privacy_request_id, action_type) -> None: ...
    def signal_task_complete(self, privacy_request_id, collection_address, data) -> None: ...

Temporal Workflow Hierarchy

Three workflow layers replace the Celery checkpoint system. Each layer has its own event history in the Temporal UI.

Graph Traversal: DAG-Ordered Concurrency

All collection nodes launch concurrently as child workflows. Each waits on wait_condition until its upstream dependencies complete. Independent branches run in parallel naturally.

Task Type Strategies

NodeExecutionWorkflow dispatches by task type. New types = new branch, no changes to orchestration.

What Changed vs. What Stayed

New / Modified

  • DSREngine protocol + factory
  • CeleryDSREngine wraps existing dispatch
  • TemporalDSREngine starts workflows
  • 3 workflow definitions (lifecycle, traversal, node)
  • 15 activity definitions wrapping existing code
  • queue_privacy_request() delegates to engine
  • Callback endpoint sends Temporal signal when flag on
  • Docker: +2 containers (Temporal server + UI)

Unchanged

  • All connectors (BaseConnector, SaaSConnector, DB connectors)
  • Graph construction (Traversal, DatasetGraph, Kahn's algorithm)
  • GraphTask execution (retrieve_data, mask_data)
  • RequestTask model (still written for API visibility)
  • ExecutionLog audit trail (still created per collection)
  • Celery path (fully functional when flag is off)
  • Admin UI (reads same RequestTask / ExecutionLog data)

Infrastructure

Temporal shares the existing PostgreSQL instance (creates temporal and temporal_visibility databases alongside fides). Redis is retained for caching but is no longer the task broker. The Temporal worker replaces the Celery DSR worker.
